# HnS: Don't Get Caught By It!
A maze-based hide-and-seek game with a model-based reflex agent as a seeker and a player as the hider.

# How to Play

Simply download HnS through `pip`.

```bash
pip install hns-maze
```

To run it, just execute:

```bash
hns-play
```

# Controls

`W/Up`                  — Move up

`S/Down`                — Move down

`A/Left`                — Move left

`D/Right`               — Move right

`C`                     — Toggle walking/sneaking

`M`                     — Open/close map

`Scroll Up/Scroll Down` — Zoom-in/zoom-out the map

# Requirements
1. Python >= 3.8
2. PyGame >= 2.6
